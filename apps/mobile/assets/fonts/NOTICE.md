# Fonts used by the Galaxia mobile app

Same static Fraunces, Inter, and ZodiacGlyphs instances as
`apps/web/app/s/[token]/opengraph-image/fonts/`.
SIL Open Font License 1.1 (`OFL.txt`). See that folder's `NOTICE.md` for how
they were subset. ZodiacGlyphs is the 22-codepoint Noto Sans Symbols merge
for SIGN_GLYPH / BODY_GLYPH; Inter/Fraunces are Latin-only and cannot paint
the wheel.
