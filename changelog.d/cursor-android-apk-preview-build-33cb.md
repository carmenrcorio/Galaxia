a side-loadable `.apk`. The Android keystore was auto-generated by EAS on the
first build. Build status URL and the direct `.apk` artifact URL are reported
in the task output / PR description.

here (no secret provided, and guessing values is out of scope), so the APK
installs and launches but will not get past startup until those are added as
`preview`-profile EAS environment variables (`eas env:create` or the Expo
dashboard), per `docs/ship-checklist.md` §Mobile item 3. Carried over from the
PR #226 fragment's second `[OPEN]` item.
