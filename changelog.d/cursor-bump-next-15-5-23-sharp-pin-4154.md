## Next.js bumped to 15.5.23 + sharp pinned to >=0.35.0 (branch `cursor/bump-next-15-5-23-sharp-pin-4154`) — 2026-08-20

**Trigger**: Security audit (P2) found `next@15.5.19` carried 8 disclosed CVEs (SSRF/DoS in Server Actions, SSRF via `rewrites()`, cache confusion, unauthenticated Server Function endpoint disclosure, Image Optimization API SVG DoS, unbounded Server Action payload on Edge), all fixed in `>=15.5.21`. `apps/web` doesn't use `"use server"`, `rewrites`/`redirects`/`images.remotePatterns`, or `next/image` (confirmed by grep/`next.config.mjs` review), so live exploitability was low today, but this closes the CVEs before any of those features get added later.

`[CHANGED]` **`next` bumped `15.5.19` → `15.5.23`** (latest 15.5.x patch; `apps/web/package.json`'s `^15.0.0` range already covered it, so only `pnpm-lock.yaml` moved — no major/minor jump). Clears all 8 next-specific advisories from `pnpm audit --prod` (56 → 48 vulnerabilities). Verified with `pnpm --filter @galaxia/web typecheck` and `build` (all 38 routes) both passing, and no new peer-dep warnings beyond the pre-existing, unrelated `apps/mobile` react-native/react-native-screens ones. web-only; `apps/mobile` has no `next` dependency and was not touched.

`[CHANGED]` **`sharp` pinned to `>=0.35.0` via a new root `pnpm.overrides` block** (resolves to `0.35.3`). The next bump alone doesn't clear the nested `sharp` advisory (`GHSA-f88m-g3jw-g9cj`, vulnerable `<0.35.0`) because `next@15.5.23` still declares `sharp: "^0.34.3"` as an optional dependency. `sharp` backs the `/_next/image` optimization route, which is live by default here even with zero `next/image` usage in app code (`images` isn't disabled in `next.config.mjs`) — so this was verified with a real smoke test against a running `next start` server: `/_next/image` correctly resized a test PNG (64x64, and a 256px request correctly capped at the 200x200 source) and transcoded to WebP on `Accept: image/webp`, confirming the pin doesn't break the route. `pnpm audit --prod` drops to 47 vulnerabilities (sharp advisory cleared). Combined with the next bump: **56 → 47** next+sharp-relevant advisories cleared; the remaining 47 are all pre-existing `apps/mobile`/`expo` advisories (`tar`, `send`, etc.), unrelated and out of scope for this change.
