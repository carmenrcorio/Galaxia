## Fix chart export colours and backdrop-filter clipping (branch `cursor/fix-chart-export-colors-and-clipping-6f81`) — 2026-09-10

**Trigger**: two cloud-agent branches independently wired the same image-export task in parallel; `cursor/wire-image-export-biwheel-galaxy-6d42` merged first (PR #178), so this branch instead fixes two real capture bugs its `ChartWheel`/`ShareImageButton` wiring did not catch.

`[FIXED]` `ChartWheel` inside an image export painted every `var(--x)` SVG colour (gold ASC/MC labels, cream planet glyphs, mist2 house numbers, teal/rose/mist aspect lines) as black. `html-to-image` clones an `<svg>` root with a native `cloneNode(true)` and never re-visits its descendants, so a `fill="var(--x)"` presentation attribute inside the captured wheel has no `:root` definition in the exported document. Added an additive `exportSafe?: boolean` prop (default `false`, zero live-visual change) that swaps every SVG colour for a literal hex from a new `EXPORT_COLOR_LITERALS` table (`apps/web/lib/design.ts`, drift-guarded against `globals.css` `:root` by `lib/design.test.ts`), and passed `exportSafe` at every `ChartWheel` call site inside a `ChartImageExport` capture (`/chart`, `/app/person/[id]`, `/chart/compare`, `/app/compare`, `/s/[token]` single and compare). `chart-pdf-export.tsx`'s print path is unaffected — it uses the live DOM, not this raster capture.

`[FIXED]` A wheel export with the full house ring (the `.glass-card` wrapper, `backdrop-filter: blur(22px) saturate(1.15)`) rasterized with the bottom portion blank: the MC label and the watermark went missing, replaced by flat background colour. Root cause is a Chromium rasterizer bug — it leaves everything below/around an element with an active `backdrop-filter` unpainted when it rasterizes html-to-image's `foreignObject`-based SVG onto a canvas. `ShareImageButton` now calls a `toPngWithoutBackdropFilterClip()` helper that replicates `toPng`'s internal pipeline (`toSvg` → `<img>` → `<canvas>`) while stripping `backdrop-filter` from the baked SVG first. A static export has already flattened whatever sat behind the card, so dropping the filter costs nothing visually.

`[ADDED]` Unit tests: `chart-wheel.test.ts` (`exportSafe` literal-hex coverage, default behaviour unchanged) and `design.test.ts` (drift guard against `globals.css`).
