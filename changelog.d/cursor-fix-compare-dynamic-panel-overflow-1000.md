## Fix "Your dynamic" panel overflow on mobile Compare (branch `cursor/fix-compare-dynamic-panel-overflow-1000`) - 2026-08-31

**Trigger**: At 390px, `/app/compare`'s "Your dynamic" metrics panel could grow wider than the viewport, so a label and value packed onto one fixed-width flex row wouldn't wrap: instead the row collided or ran off the edge, cutting values like "Workable" and "Some friction" short. Reddit traffic to Compare is mobile-heavy, so this hit the core loop directly.

`[FIXED]` **Constrained the "Your dynamic" score rows to `max-width: 100%` and let them wrap.** Added a shared `.dyn-row` / `.dyn-row-label` / `.dyn-row-value` CSS rule set (`flex-wrap: wrap`, `min-width: 0`) applied to both `/app/compare`'s own row markup and the shared `DynamicTableSection` (used by `/chart/compare` and compare share snapshots). On narrow widths the label and value now stack onto their own lines instead of forcing a fixed-width row past the edge; verified with a 260px stress test (pre-fix: `scrollWidth` 262 with label/value text touching; post-fix: `scrollWidth` 260, clean stack, no truncation) and confirmed `/chart/compare` still renders unchanged at 390px. No score, word, or color logic changed.
